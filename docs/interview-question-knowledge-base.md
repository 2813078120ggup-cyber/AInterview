# 面试模拟题内容知识库

## 文档库基础信息

名称：AI 面试模拟题库

标签：面试模拟；Java后端；Spring；MySQL；算法；综合素质

介绍：本知识库来自 AI 多模态智能模拟面试评测平台的初始化题库数据，覆盖 Java 核心基础、Spring 与微服务、MySQL 数据库、算法与数据结构、综合素质五类模拟面试题。可用于 OpenTalking 数字人或 AI 面试官在面试过程中抽题、追问、讲解参考答案、辅助评分与生成练习反馈。

建议用途：创建文档库后导入本文档，让虚拟人围绕题目内容进行播报、答疑和追问。

## 使用规则

- 候选人端只应展示题干、题型、选项、分值和难度。
- 标准答案、参考答案、解析和评分要点仅供面试官、管理员、AI 评分和面试复盘使用。
- 选择题可直接核对标准答案；简答题和编程题应结合参考答案、关键点、解释和表达质量综合评分。
- 综合素质题建议使用 STAR 结构评估候选人的背景、任务、行动、结果和复盘能力。
