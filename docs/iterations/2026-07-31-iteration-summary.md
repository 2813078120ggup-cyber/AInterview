# 2026-07-31 前端体验与移动端适配迭代总结

> 迭代日期：2026-07-31  
> 项目名称：AInterview  
> 代码库数据库版本：Flyway V20  
> 发布状态：本地开发与验证完成，尚未部署云服务器

## 1. 迭代目标

本次迭代聚焦候选人训练闭环、工作台信息效率、报告生成与打印体验，以及后续小程序改造前的移动端基础能力。

- 让候选人在面试结束后能够记录心得，并通过主观评分与 AI 评分观察进步。
- 提高管理员和候选人工作台的行动指引与真实数据密度。
- 缩短新模拟面试报告的生成等待时间。
- 保证报告打印内容可收敛到单张 A4。
- 先完成 Web 端核心界面的 320–375px 手机适配，为后续小程序组件化迁移建立布局基础。

## 2. 已完成内容

### 2.1 面试心得与成长可视化

- 新增 Flyway V20，一场已结束面试对应一份可持续编辑的候选人心得。
- 心得包含自评分、信心程度、核心心得、表现亮点、待改进项和下一步计划。
- 候选人端新增心得列表、待复盘入口、完成度和成长趋势。
- 趋势图同时展示自评分和已发布的 AI 报告评分，不重复存储 AI 分数。
- 修复心得弹窗点击关闭、取消或 Esc 后被查询参数再次打开的问题。

### 2.2 工作台与报告体验

- 管理员工作台新增今日安排、待处理事项、近七天趋势、系统状态、快捷入口和手动刷新。
- 候选人工作台优先展示下一步行动、训练重点、本周练习、待办、报告和最近能力变化。
- 报告类 AI 任务改为高优先级有界并发，同一报告内主观题最多三路并行评分。
- 报告打印版按 A4 可用高度动态缩放，压缩无效留白并保留关键评测内容。

### 2.3 手机端公共框架

- 候选人端和管理端的桌面侧栏在手机端改为抽屉导航，支持遮罩、关闭按钮和 Esc。
- 通知中心在手机端改为挂载于页面根节点的全宽底部抽屉，避免受粘性页眉定位影响；增加关闭按钮、页面滚动锁定、未读状态、独立列表滚动和底部安全区。
- 候选人端右上角头像改为账户中心快捷入口，手机端可直接进入账户资料与安全设置。
- 管理端数据表格在窄屏自动转换为信息卡片，保留字段标签和业务操作。
- 统一补充安全区、触控目标、长文本换行、输入控件和横向溢出保护。
- 登录页、工作台、候选人管理、面试管理、题库、系统设置、报告和心得等核心页面补充窄屏间距与操作布局。

### 2.4 面试大厅与创建练习

- 大厅顶部双入口在手机端保持并列，文字可安全收缩。
- 面试卡片重排状态、标题、时间、编号和操作区，状态标签与按钮不再超出卡片。
- “创建模拟练习”改为手机端底部抽屉、桌面端居中弹窗。
- 弹窗正文独立滚动，标题、关闭按钮和底部操作固定可见；面试官风格改为两列触控选项。
- 弹窗打开时锁定页面滚动，并支持遮罩、关闭、取消和 Esc 退出。

### 2.5 面试流程、日历与能力图表

- 面试房间在手机端优先显示当前题目和回答区，题目目录调整到其后。
- 录制媒体、答题控制、结束确认和自由面试页面完成窄屏重排。
- 面试日历改为七列移动网格，避免日期内容被压缩或横向滚动。
- 综合能力折线图在手机端展示最近六场，保留真实场次、分数与日期，不再使用桌面最小宽度。
- 四维能力雷达图限制在卡片内部，并增加适配窄屏的分项数值列表。

### 2.6 管理端面试首屏加载

- 修复管理员登录后首次进入手机端“面试管理”时列表偶尔为空的问题。
- 修复面试列表已经渲染且空白区域可以点击，但外层超长卡片因视口动画阈值无法满足而始终透明的问题。
- 面试列表接口独立优先加载，不再等待候选人、题库和报告接口全部返回。
- 辅助接口分项失败时保留可用面试数据，并在页面提示失败范围与重试按钮。
- 页面从后台切回前台时执行一次静默刷新，减少登录跳转和移动浏览器挂起导致的旧数据。

### 2.7 模型服务与面试回顾

- 统一 DeepSeek、语音识别、浏览器语音和 OpenTalking 等服务卡片的手机端布局。
- 模型服务字段在窄屏改为标签在上、值在下，长 URL、模型名与脱敏密钥可完整换行；状态标签、操作按钮和编辑弹窗不再超出视口。
- 面试回顾不再直接输出题目选项 JSON，改为可读的选项卡片。
- 客观题题型统一中文化；判断题显示“正确/错误”，候选人选择显示对应选项内容，未作答使用明确空状态。

## 4. 小程序迁移说明

本次完成的是 Web 端移动响应式基础，不等同于已经生成小程序。后续迁移仍需要：

- 将 React Router、浏览器存储、文件选择、录音录像、权限申请和下载能力替换为目标小程序平台 API。
- 抽取请求层、鉴权状态、业务类型和表单校验为跨端模块。
- 将 DOM、SVG 和浏览器媒体接口较重的页面改造成小程序原生组件或跨端框架组件。
- 在真机验证摄像头、麦克风、后台切换、弱网续传、视频分段上传和长列表性能。
