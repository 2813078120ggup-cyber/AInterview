# 部署与网络知识库

## 1. 容器与运行时

| 组件 | 当前镜像/技术 | 职责 |
|---|---|---|
| 后端构建 | Maven 3.9.9 + Eclipse Temurin 17 | 编译 Spring Boot JAR。 |
| 后端运行 | Eclipse Temurin 17 JRE | 以非 root 用户运行 API。 |
| 前端构建 | Node 20 Alpine | 执行 `npm ci` 与 `npm run build`。 |
| Web 服务 | Nginx 1.27 Alpine | 托管 SPA、反向代理 API 和 OpenTalking。 |
| 数据库 | MySQL 8.0.36 | 持久化业务数据与 Flyway 历史。 |
| 缓存 | Redis 7.2 Alpine | 缓存、验证码冷却等短期状态。 |

Docker Compose 定义 `mysql`、`redis`、`backend`、`frontend` 四个服务，并使用独立的 `mysql_data`、`redis_data`、`media_data` 卷。后端依赖 MySQL 与 Redis 健康检查通过后再启动。

## 2. Nginx 路由

| 路径 | 上游 | 作用 |
|---|---|---|
| `/` | 静态文件 | React SPA，未知前端路由回退至 `index.html`。 |
| `/api/` | `backend:8080/api/` | 同源 API 代理。 |
| `/opentalking/` | `${OPENTALKING_UPSTREAM}` | 同源数字人服务代理，关闭缓冲并使用长读超时。 |

生产配置支持 HTTP 80 与 HTTPS 443，TLS 仅启用 1.2/1.3。证书和私钥必须挂载或由服务器管理，不打进前端镜像。

## 3. 环境变量与密钥

- 变量清单以根目录 `.env.example` 为准；生产使用不提交 Git 的 `.env` 或受控密钥系统。
- `MYSQL_ROOT_PASSWORD`、`MYSQL_APP_PASSWORD`、`REDIS_PASSWORD`、`JWT_SECRET` 是启动必需项。
- DeepSeek、短信、邮箱等外部服务凭据按需配置，未配置时系统应返回明确的不可用状态。
- `OPENTALKING_UPSTREAM` 根据部署拓扑设置；默认指向 `host.docker.internal:8210` 仅适合对应宿主机拓扑。

## 4. 数据库与升级

- 首次创建空 MySQL 数据卷时，Docker 读取 `docs/database/docker-init/01-ai-interview-init.sql`。
- 后端启动后由 Flyway 校验并执行运行时迁移。生产更新不再手工执行历史 SQL。
- 数据库迁移只前进，应用镜像回滚不等于数据库回滚；升级前必须备份并准备恢复方案。

## 5. 实时媒体网络

- OpenTalking / WebRTC 在生产中需要 HTTPS、正确的同源代理和可用的 STUN/TURN。
- 不要用本地测试配置覆盖生产的 STUN/TURN、relay 策略、凭据或服务端网络参数。

## 6. 发布前检查

```powershell
cd D:\Ainterview\backend
mvn test

cd ..\frontend-react
npm run build

cd ..
docker compose config --quiet
```

上线后检查容器健康、Flyway 版本、HTTPS 证书、`/api` 与 `/opentalking` 代理、登录、模拟面试、自由简历面试和报告生成。详细过程见 `docs/deployment/`。

服务器的公网/内部端口、Docker 卷和服务器持久化文件见 [云服务器端口与文件存放说明](../deployment/SERVER_PORTS_AND_STORAGE.md)。
