## 已完成：智能面试与候选人体验

| 模块 | 已交付内容 |
|---|---|
| 自由简历面试 | 支持 PDF、DOCX、TXT、Markdown 简历解析，目标岗位选择、十轮追问、可恢复会话历史和报告生成。 |
| 异步 AI 任务 | 数据库持久化任务、轮询、重试、幂等提交、答案优先落库与任务恢复。 |
| 能力报告 | 候选人工作台、历史与简历入口、能力雷达图、趋势图、低样本提示及 PDF 报告导出优化。 |
| 面试交互 | 选择题提交反馈、语音回答/朗读控制、超时处理、统一页面过渡、深色模式与候选人导航；主观题前后端统一最多追问 3 次，重复请求幂等，达到上限后确定性收尾并跳题。追问使用同题上下文，经过重复/越界/多问题校验、一次重试和确定性兜底。 |
| 进度与保存 | 当前题号和剩余时间由服务端恢复，刷新后续接未完成 AI 任务；答案提供草稿、保存中、已保存、失败重试、离线补交和离开保护。 |
| 面试方式与录制 | 入场后先选择文字、语音或视频面试，不再自动使用浏览器朗读题目。语音/视频按题分段录制并强制顺序作答；视频目标为 1280×720、15fps，管理端可按题查看受保护媒体与题目/回答/追问时间轴。 |

## 已完成：反馈工单与站内通知

| 模块 | 已交付内容 |
|---|---|
| 候选人反馈 | 创建/编辑草稿、正式提交、截图附件、工单列表与详情、双向留言、未读提示和阅读位置；只能访问本人提交的工单。 |
| 管理端处理 | 全量查询、状态/类型/处理人筛选、管理员转派、开始处理、解决、关闭、恢复处理和留言；反馈工单菜单位于算法题目之后。 |
| 工单一致性 | 状态变更、转派和留言在事务内锁定工单；状态/转派使用版本校验，留言使用 `clientRequestId` 幂等；关闭后后端禁止继续留言和上传附件。 |
| 站内通知 | `site_notification` 持久化通知列表、未读数量、单条/全部已读；工单提交、转派、回复和状态变更通知对应用户。 |

## 已完成：学习资料中心与 PDF 批注

| 模块 | 已交付内容 |
|---|---|
| 管理端资料 | 管理员上传 PDF、填写标题/说明、发布/下线、删除资料和控制是否允许下载；原始文件复用私有媒体存储与现有上传安全链路。 |
| 查看权限 | 按用户或角色保存查看/批注权限和过期时间；候选人列表、详情、PDF 内容、下载和批注接口均由后端再次校验，不依赖前端隐藏入口。 |
| PDF 阅读器 | `pdfjs-dist` 渲染页面和文本层，支持翻页、缩放、文字选择高亮、页面便签、个人笔记编辑/删除和下载权限。 |
| 批注数据 | V26 保存 PDF 版本、页数、SHA-256 和批注归一化坐标；批注默认仅本人可见，更新使用版本号校验，原始 PDF 不被修改。 |
| 交付配置 | 前端 Docker 构建使用 Node 22.13；Nginx 显式以 `application/javascript` 返回 `.mjs` worker，避免 PDF.js fake worker 动态导入失败。 |
