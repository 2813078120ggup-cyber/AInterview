| 模块 | 已交付内容 |
|---|---|
| 用户与权限 | 注册、登录、JWT 鉴权、刷新令牌、角色与权限控制、候选人/管理端路由。 |
| 题库与面试 | 题库、题库分类和题目维护；创建、开始、作答、结束、回顾面试；选择题与主观题流程。 |
| 评测与报告 | AI 评测接口、客观题确定性评分、主观题评估、面试报告和已结束面试的报告查看。 |

## 已完成：智能面试与候选人体验

| 模块 | 已交付内容 |
|---|---|
| 自由简历面试 | 支持 PDF、DOCX、TXT、Markdown 简历解析，目标岗位选择、十轮追问、可恢复会话历史和报告生成。 |
| 异步 AI 任务 | 数据库持久化任务、轮询、重试、幂等提交、答案优先落库与任务恢复。 |
| 能力报告 | 候选人工作台、历史与简历入口、能力雷达图、趋势图、低样本提示及 PDF 报告导出优化。 |
| 面试交互 | 选择题提交反馈、语音回答/朗读控制、超时处理、统一页面过渡、深色模式与候选人导航；主观题前后端统一最多追问 3 次，重复请求幂等，达到上限后确定性收尾并跳题。追问使用同题上下文，经过重复/越界/多问题校验、一次重试和确定性兜底。 |
| 进度与保存 | 当前题号和剩余时间由服务端恢复，刷新后续接未完成 AI 任务；答案提供草稿、保存中、已保存、失败重试、离线补交和离开保护。 |
| 面试方式与录制 | 入场后先选择文字、语音或视频面试，不再自动使用浏览器朗读题目。语音/视频按题分段录制并强制顺序作答；视频目标为 1280×720、15fps，管理端可按题查看受保护媒体与题目/回答/追问时间轴。 |

## 已完成：AI 配置、虚拟人与可观测性

| 模块 | 已交付内容 |
