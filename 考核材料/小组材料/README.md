# AI 智面（Ainterview）智能面试评测系统

**版本：** v1.0.0　**组长：** 张嘉豪　**小组成员：** 张嘉豪、高弨、乔佳琪、武心怡

## 一、项目简介

AI 智面是一套基于 Spring Boot + React 的 AI 模拟面试评测系统。候选人完成语音/文字面试后，系统调用感知模块对作答进行多维度分析，融合评分引擎生成可追溯的评测报告。

**所选感知模块（2 项）：**
1. **语音分析** —— 独立 Python 服务（librosa），对录音分析语速、流利度、情绪稳定性、清晰度四维子分，写入评测的可追溯证据；
2. **文本理解与评价** —— 语义评分引擎对回答文本按分档规则评价，输出专业/表达/逻辑/应变四维分与可追溯证据（输入摘要、命中分档、规则版本）。

**所选扩展能力（1 项）：简历与题目** —— 简历解析 + 基于岗位画像的智能组卷。

**拓展功能（超出考核要求的加分项）：** 多模态面试（文字/语音/视频）与 AI 追问、数字人面试官（OpenTalking）、算法练习与隔离判题、企业多租户招聘闭环、学习资源中心、反馈工单、面试反思与能力看板、自由面试、AI 助手与生成审计、AI 治理与敏感数据脱敏、安全与可观测体系、微服务架构。

## 三、启动命令

```bash
# 1. 配置环境变量（复制模板并填写）
cp config/.env.template .env

# 2. 一键构建并启动全部服务
docker compose up -d --build

# 3. 查看服务状态（backend / frontend / mysql / redis / voice-analysis / cloud-gateway）
docker compose ps

# 4. 浏览器访问
# 前端入口: http://localhost（nginx 反代 /api 到网关）
```

数据库迁移（Flyway）在 backend 启动时自动执行，无需手动建表。

| 功能 | 操作入口 |
| --- | --- |
| 感知模块一：语音分析 | 候选人以**语音/视频模式**作答 → 评分完成后 → 报告页「逐题语音分析」区块 |

## 六、功能测试输入、预期结果与实际结果（摘要）

| 功能 | 测试输入 | 预期结果 | 实际结果 |
| --- | --- | --- | --- |
| 语音分析 | 一段 ≥30s 的 webm 录音作答 | 报告逐题展示语音分与四维子分，未录音题目显示"未评估" | 通过（voice_score 落库，四维子分+证据完整） |
| 文本理解与评价 | 一段简答题文字回答 | 报告逐题展示总分、分档、四维分、评语与评价依据 | 通过（text_evidence 落库，含输入摘要与规则版本） |
| 简历与题目 | 上传一份 PDF 简历 | 解析出技能画像并生成对应题目 | 通过 |
| 非法输入 | 上传非音频文件 / 越权访问他人报告 | 明确报错提示 / 403 拦截 | 通过（结果可复现） |

## 七、外部模型/服务与调用方式

| 服务 | 用途 | 调用方式 | 配置项（占位符） |
| --- | --- | --- | --- |
| DeepSeek | 文本语义评分、报告生成、智能组卷 | HTTPS REST（OpenAI 兼容协议） | `DEEPSEEK_API_KEY=sk-****` |
| 语音分析服务 | 录音四维分析 | 内部 HTTP `POST /v1/analyze`（voice-analysis:8500） | 无密钥，容器内网互通 |
