# 作业02 / 作业03 打包说明（通用指引）

> 作业02、作业03 需提交**可运行的代码压缩包**，由各成员从项目代码中抽取本人负责的部分打包。以下为打包内容与检查清单。

## 作业02 —— Vue3 页面与交互（5 分）
文件名：`作业02-学号-姓名-Vue3页面与交互.zip`

| 成员 | 建议选取的页面 |
| --- | --- |
| 张嘉豪 | 面试预约页（预约表单+列表刷新） |
| 高弨 | 管理端评分任务/报告页（或本人参与的前端部分） |
| 乔佳琪 | 简历上传与组卷页 |
| 武心怡 | 报告详情页（逐题语音/文本区块） |

zip 内必须包含：
1. 页面组件源码（从 `frontend-react/src/` 抽取本人负责的页面及其依赖）；
2. `运行说明.md`：依赖版本（Node 20+、React 19）、安装命令（`npm install`）、启动命令（`npm run dev`）、访问入口、演示步骤；
3. 页面需体现：接口调用、状态处理、表单校验、加载/空数据/错误状态。

## 作业03 —— Spring Boot 接口、数据与权限（7 分）
文件名：`作业03-学号-姓名-SpringBoot接口数据权限.zip`

| 成员 | 建议选取的接口域 |
| --- | --- |
| 张嘉豪 | 面试预约域（Interview/InterviewQuestion 接口） |
| 高弨 | 评分与感知域（report 接口、voice-analysis 接入、evaluation 数据） |
| 乔佳琪 | 简历与组卷域（简历解析、组卷接口） |
| 武心怡 | 报告查询域（报告详情、权限拦截示例） |

zip 内必须包含：
1. 本人负责的 Controller/Service/实体/Mapper 源码；
2. 数据库脚本（可直接引用项目 Flyway 迁移中本人相关的版本，如高弨附 V48/V49）；
3. `API清单.md`：列出 ≥3 个关联接口（方法/路径/参数/返回/权限角色），**必须与实际接口一致**；
4. 覆盖要求：≥3 个关联接口、2 个持久化数据表/实体、2 种角色权限、参数校验与异常返回。

## 提醒
- zip 内不含任何真实 API 密钥；
- `API清单.md` 与代码不一致是作业3扣分主因，打包前逐条核对。
