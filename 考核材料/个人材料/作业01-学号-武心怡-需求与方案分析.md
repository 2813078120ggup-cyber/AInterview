# 作业01 —— 需求与方案分析（武心怡 · 组员）

**课程：**《软件工程行业案例分析与实现》· 人工智能Ⅱ方向　**姓名：** 武心怡　**角色：** 组员（开发、测试）

## 1. 角色与目标
本人在小组中负责**前端页面与交互开发**（报告页、面试大厅等）以及**测试工作**（测试用例设计执行、《测试结果.xlsx》、项目风险分析）。目标：报告页直观展示两个感知模块的可追溯结果与"未评估"语义；系统在正常/异常/权限输入下行为正确且可复现。

## 2. 项目主要业务流程（本人负责部分加粗）
1. 候选人登录 → **面试大厅浏览/进入面试** → 作答 → 评分；
2. **报告页渲染**：总分与四维卡片 → **「逐题语音分析」区块**（语音分+语速/流利度/情绪稳定性/清晰度子分条）→ **「逐题回答评价」区块**（档位徽章+四维子分+评语+评价依据）→ 能力画像与摘要；
3. **未测维度显示"未评估"**：未录音题目的语音子分显示"—"，不误导；
4. **测试**：正常/异常/权限三类用例覆盖全链路，执行结果记录于《测试结果.xlsx》。

## 3. 核心数据对象（≥2 个）
- **ReportDetail / questionVoiceReviews / questionTextReviews（报告详情 DTO）**：前端渲染的数据契约，逐题携带语音四维子分与文本档位/评语/规则版本；
- **测试用例与风险记录**：3 条正常、2 条异常、1 条权限用例及执行证据；5 条项目风险（触发条件/影响/应对/责任人/状态）。

## 4. 所选 AI 功能的展示与验收（前端视角）
| 功能 | 前端验收标准 |
| --- | --- |
| 语音分析 | 报告页逐题展示语音分与四维子分进度条；未录音显示"未评估" |
| 文本理解与评价 | 报告页逐题展示档位徽章、四维子分、评语与"评价依据（可追溯）"（输入摘要+规则版本） |
| 异常与权限 | 非法输入有明确提示；越权访问被拦截且可复现 |

## 5. 测试与风险方案
- **测试策略**：正常用例走通全链路（登录→预约→作答→感知→报告），异常用例覆盖非法文件、外部模型超时、表单校验、题库删除约束，权限用例覆盖候选人越权/企业越权/管理员接口越权；每条记录输入、预期、实际与证据；
- **风险分析**：识别外部模型不可用、长音频性能、部署环境差异、录音格式兼容、现场数据缺失 5 条风险，逐条给出触发条件、影响、应对与责任人（详见作业04）。

内容可追溯到后续实现：`report-detail-view.tsx`（逐题语音/文本区块）、`测试结果.xlsx`、`作业04` 风险表等。
